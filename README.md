# GYOSAI - 行政書士試験 AI予測分析

令和2〜7年度の行政書士本試験問題冊子をもとに、科目配分、抽出品質、論点横断性を可視化する学習支援サイトです。

## 開発

```bash
npm install
npm run dev
```

## データ分析

`C:\Users\syunn\Downloads` に `r2_mondai.pdf` 〜 `r7_mondai.pdf` を配置して実行します。

```bash
python -m pip install -r requirements.txt
npm run analyze
```

R2〜R6はPDF内の日本語文字マップ不整合があるため、構造補助解析として扱います。R7は全文抽出を利用します。予測スコアは学習優先度の目安で、実際の出題を保証しません。

## 教材ガイド

「教材を探す」「教材ランキング」「教材診断」を追加。2026年向け模試3件を公式出典・確認日付きで掲載しています。詳細はカード内から展開できます。

- `src/materials.js`: 教材データと条件判定。料金不明は `null` のまま保持します。
- `src/Materials.jsx`: 検索、条件一致順のランキング、購入済み除外、予算0円・学習時間不足時の案内。
- 条件一致は品質評価ではありません。同条件は同順位です。週6時間の基準は運営上の目安で、合格可能性の統計モデルではありません。
- 入力は保存・送信しません。生成AI、レビュー投稿、認証、DB、管理画面、アフィリエイト計測は未実装です。
- 教材追加時は公式出典と確認日を更新し、未確認の料金・機能を推測で埋めないでください。

検証: `node --test src/materials.test.js`、`npm run build`。

次段階では教材IDを維持したままAPIへ切り替え、認証・レビュー承認・管理画面を追加します。Laravelを採用する場合は別途PHP/DB対応の公開先が必要です。模試記録ブランチの統合はその前に差分確認します。
