# GYOSAI - 行政書士試験 AI予測分析

令和2〜7年度の行政書士本試験問題冊子をもとに、科目配分、抽出品質、論点横断性を可視化する学習支援サイトです。

## 開発

```bash
npm ci
npm run dev:full
```

## データ分析

`C:\Users\syunn\Downloads` に `r2_mondai.pdf` 〜 `r7_mondai.pdf` を配置して実行します。

```bash
python -m pip install -r requirements.txt
npm run analyze
```

R2〜R6はPDF内の日本語文字マップ不整合があるため、構造補助解析として扱います。R7は全文抽出を利用します。予測スコアは学習優先度の目安で、実際の出題を保証しません。

## 教材ガイド

「教材を探す」「教材ランキング」「教材診断」を追加。2026年向け模試3件を公式出典・確認日付きで掲載しています。詳細はカード内から展開できます。

- `src/material-catalog.json`: 初期教材データ。`src/materials.js` は条件判定を担当します。料金不明は `null` のまま保持します。
- `src/Materials.jsx`: 検索、条件一致順のランキング、購入済み除外、予算0円・学習時間不足時の案内。
- 条件一致は品質評価ではありません。同条件は同順位です。週6時間の基準は運営上の目安で、合格可能性の統計モデルではありません。
- 未ログインの診断はブラウザー内だけで処理します。ログイン後の診断は自分の履歴に保存されます。
- 教材追加時は公式出典と確認日を更新し、未確認の料金・機能を推測で埋めないでください。

## React + Node.js 構成

画面はReact + Viteのままです。Node.js 24.14以上の24系と組み込みSQLiteを使用し、PHPやLaravelは不要です。

- `server/`: 同一オリジンAPI、Cookieログイン、SQLite永続化。追加のnpm依存はありません。
- マイページ: アカウント登録、ログイン・ログアウト、学習記録、診断履歴の閲覧・削除。
- レビュー: ログインして投稿。承認したものだけ公開。編集すると再承認待ちになります。
- 管理画面: 教材追加・編集・公開切替、レビュー承認・非公開、広告クリック集計、管理操作履歴。
- 広告: 管理者が広告URLを設定した教材のみ「広告」と明記してリンクを計測。契約や架空URLの自動設定はしません。
- AI補足: サーバー側の `OPENAI_API_KEY` と `OPENAI_MODEL` を設定すると利用可能。ログインした本人が希望した診断だけOpenAI Responses APIに送り、学習方法を補足します。メール・氏名は送りません。API障害時も条件診断を維持し、AI補足失敗を表示します。AI実通信はキーを設定して別途確認してください。

開発時は `npm run dev:full` で画面（5173）とAPI（8787）を起動。個別には `npm run dev` / `npm run server`。本番ビルドは `npm run build`、その成果物を含めて `npm start` で配信します。

DBは `data/gyosai.sqlite` に自動作成し、初回のみ教材を登録。再起動で管理者の編集を上書きしません。データと `.env` はGit管理対象外です。管理者になるには画面で登録した後、サーバー上で `npm run admin -- 登録したメールアドレス` を実行してください。初期管理者・初期パスワードはありません。

検証: `npm test`（権限分離、投稿承認、永続化、診断、AI障害時の動作）、`npm run build`。

GitHub Pagesでは静的版のみ動作し、APIがない場合は保存・ログインを利用不可と表示します。公開構成とバックアップは [DEPLOYMENT.md](DEPLOYMENT.md) を参照してください。別の模試記録・WordPressブランチはこの変更には混ぜていません。
